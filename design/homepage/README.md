# Homepage prototype

Standalone HTML/CSS/JS design for the new homepage (`index.html`, no build step). It is meant as the reference to port into the site's chosen stack.

- **Pitch status** (`Praticable` / `Horaires modifiés` / `Impraticable`) drives both the top banner and the hero pitch illustration. The values live in the `STATES` object in the script; on the real site they should come from a file or CMS entry the committee updates. The floating "Aperçu" switch is for review only and should be removed.
- **News dates are examples.** The current site's news items have no dates; the copy is real, the dates are placeholders.
- **Partner and funder logos are text placeholders** until the real logo files are exported from the current site.
- **Map** is a schematic drawing with links to Google Maps, Apple Plans and Waze (coordinates 50.813992, 4.397711), so no third-party map loads without consent.
- Colours (pitch blue + ball yellow) and fonts (Big Shoulders Display, Figtree) are a proposal, not the club's official identity.
